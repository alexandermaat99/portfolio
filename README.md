# alexandermaat.com

Alex Maat's personal portfolio, built with Next.js (App Router), React, and Tailwind CSS. Deployed on Vercel.

## Development

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm run lint
```

## Editing content

- **Sections and nav order** live in `app/sections.ts`; the photo nav and page both read from it.
- **Section content** lives in `app/components/sections/`, one file per section. Add a new section by creating a component that uses `SectionLayout`, adding an entry to `app/sections.ts`, and rendering it in `app/page.tsx`.
- **Resume** is served from `public/alexandermaatresume.pdf`.
- **Social share card** is generated by `app/opengraph-image.tsx`.
